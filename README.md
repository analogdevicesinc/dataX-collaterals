# DataX Collaterals

This repository provides a centralized collection of practical resources for learning, exploring, and demonstrating DataX.

It brings together workshop materials, hands-on exercises, example applications, and end-to-end demos that showcase how DataX can be used to build and connect data-driven applications across different platforms and use cases.

The repository is intended to support a variety of DataX workshops and demonstrations, from introductory sessions focused on DataX concepts and basic workflows to more advanced scenarios combining multiple devices, services, applications, and software components.

## What you can find here

The repository may include:

- **Workshops** – structured, hands-on sessions designed to introduce DataX concepts and guide users through practical workflows.
- **Example applications** – reference implementations showing how applications can integrate with and make use of DataX.
- **Demos** – complete demonstration scenarios highlighting DataX capabilities in realistic or application-oriented setups.
- **Exercises and tutorials** – step-by-step examples that can be used for training, experimentation, or self-paced learning.
- **Supporting resources** – configuration files, scripts, diagrams, datasets, and other assets required to reproduce the workshops and demos.

## Purpose

The goal of this repository is to make DataX easier to explore, demonstrate, and adopt through practical examples.

Rather than focusing on a single application or hardware setup, it is designed as an evolving collection of reusable DataX scenarios. New workshops, applications, and demos can be added over time to illustrate different ways of using DataX and integrating it into broader systems.

Whether you are attending a DataX workshop, preparing a demonstration, evaluating DataX for a new application, or simply experimenting with the technology, this repository provides a practical starting point.

## About DataX

The ADI DataX technology stack is a highly adaptable and open that bridges the gap between signal chains and applications. It connects applications to the physical world through industry-standard APIs, enabling portability across processing platforms and operating systems and easier integration into the customer’s ecosystem of choice.

The examples in this repository focus on putting these concepts into practice. Each workshop or demo illustrates a particular DataX workflow, integration pattern, or application scenario that users can reproduce, modify, and extend.
